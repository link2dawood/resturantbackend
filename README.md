# Restaurant Backend Management System

Laravel 12 application for multi-store restaurant backend: daily reports, expenses, COA/vendors, bank reconciliation, third-party platform fees, P&L, merchant fee analytics, and more.

- **Quick reference for tasks:** See **[CURSOR.md](CURSOR.md)** — project overview, key paths, Merchant Fees nav/routes, Exceptions Report, Download/Upload log, Admin Reports. Update CURSOR.md when making core changes.
- **Full documentation:** All docs and markdown files are in the **[docs/](docs/)** directory. Start with [docs/README.md](docs/README.md) for the index.
