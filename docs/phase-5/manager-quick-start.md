# Weekly Inventory & Ordering — Quick Start

For the store manager. Everything below happens on your phone or a tablet.

---

## Monday morning: count what's on the shelf

You'll get an email at 6am with a link. Or open **Inventory → Weekly Count**.

1. The page lists every item, grouped by category (Meats first, then Breads, and so on). Tap a category heading to open or close it.
2. For each item, type how much you have **in the unit shown next to the box**. If it says `portion`, count portions. If it says `case`, count cases.
   - Last week's number is shown beside each box so you can sanity-check yourself.
   - Under the item name it tells you the pack size, for example *53 portion per box*.
3. The bar at the top shows how far along you are: **45 of 90 items counted**.
4. **Your work saves itself every 30 seconds.** You can put the phone down, serve a customer, and come back. You can also tap **Save draft** at any time.
5. Need to explain something? Tap **Add note** on that item, for example "2 boxes damaged, not counted".

When every item is counted, tap **Submit week**. Confirm in the box that appears.

> After you submit, the week locks. If you need to change something, ask an admin to unlock it.

---

## Straight after: check the order suggestions

Submitting takes you to **Order Suggestions** automatically.

For each item the system works out:

```
Suggested order  =  your stock target  −  what you just counted
```

Everything is in the unit you order in, so "11" against Steak means **11 boxes**.

- Items you don't need are hidden. Untick **Hide items that need no order** to see them all.
- **Change any number you like.** Type over it. Anything you change is marked *overridden* so the office can see it was a judgement call, not a system number.
- Check the vendor on each line. Change it if you're buying elsewhere this week.

Tap **Generate Order**. You get one draft order per vendor.

---

## Send the orders

You land on the **Orders** page with a draft for each vendor.

For each order:

1. Tap **View** to check the lines. While it's a draft you can still change quantities, prices, add notes, or move a line to a different vendor.
2. Tap **View Vendor Report**. This is the page you send:
   - **Copy as text** — paste into WhatsApp or a text message
   - **Email {vendor}** — opens your mail app with the order already written
   - **Download PDF** — a proper purchase order to attach
   - **Print** — a clean sheet, no menus or buttons
3. Once you've actually sent it, tap **Mark placed**.

> Marking it placed locks the lines, because that's what the vendor was told. You can still cancel it or mark it received.

---

## When the delivery arrives

Open the order and tap **Mark received**. That's it.

---

## Need a second order this week?

Busy week? On any Order 1, tap **Duplicate for Order 2**. It copies the same
lines at the same quantities into a new draft. Edit the numbers down to just
what you need, then send it the same way.

---

## Your dashboard

**Inventory → Dashboard** shows four things at a glance:

| Widget | What it tells you |
|---|---|
| This week's count | How many items you've counted, or "Not started" |
| Pending orders | Drafts you haven't sent, and orders you're still waiting on |
| Low stock | Items at or below their reorder point |
| Variance alerts | Where last week's numbers didn't add up |

Below that, **Recent activity** shows the last five things that happened.

---

## Reordering something you've bought before

**Orders → Order history** lists everything you've ordered, grouped by vendor.

- Tap the arrow on any row to see its line items.
- Tap **Reorder** to copy that order into a new draft for this week.
- The **What you order, per week** table shows your averages, for example *Steak, 6 box/week*. Useful when setting stock targets.

---

## The bell icon

Top right of every page. It shows how many unread notifications you have:

- Monday: time to enter this week's inventory
- Wednesday: still waiting, if you haven't submitted yet

---

## If something looks wrong

| Problem | What to do |
|---|---|
| An item is missing from the count | Inventory → Items → **Add Item** |
| The pack size is wrong (a box now holds 48, not 53) | Inventory → Items → Edit → **Portions per Box/Unit**. Fix it as soon as you notice; every order quantity comes from this number. |
| Suggestion says 0 but you need stock | The item probably has no stock target. Ask an admin to set one. |
| You submitted the week too early | Ask an admin to unlock it. |
| An item says "no vendor" | Inventory → Items → Edit → tick the vendors that sell it. |
