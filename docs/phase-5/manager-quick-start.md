# Weekly Inventory & Ordering — Manager Quick Start

For the store manager. Everything below happens on your iPad or phone.

Your two jobs are **counting what is on the shelf** and **placing and checking in
the orders the owner approves**. Deciding what to buy is the owner's job, so you
will not see order suggestions or a Build Order button.

---

## Monday morning: count what's on the shelf

Open **Inventory → Weekly Count**. You will also see a bell notification for it.

1. The page lists every item, grouped by category (Meats first, then Breads, and
   so on). Tap a category heading to open or close it.
2. For each item, type how many **boxes, cases or jugs** you have. You count in
   the same unit you order in, so if Steak comes in boxes, you count boxes. The
   unit is printed next to every box.
   - Part of a box is fine. Half a box is `0.5`.
   - Last week's number sits beside each box so you can sanity-check yourself.
3. The bar at the top shows how far along you are: **45 of 90 items counted**.
4. **Your work saves itself every 30 seconds.** You can put the iPad down, serve
   a customer, and come back. You can also tap **Save draft** at any time.
5. Need to explain something? Tap **Add note** on that item, for example
   "2 boxes damaged, not counted".

When every item is counted, tap **Submit week**. Confirm in the box that appears.

> After you submit, the week locks and your counts go to the owner. If you need
> to change something, ask an admin to unlock it.

That is your Monday done. The owner takes it from here.

---

## When the owner approves an order

You get a notification, and an email with the order sheet attached as a PDF.

The notification tells you **how that vendor takes orders**, because they are all
different: some by phone, some by email, some through a rep. It is set per
vendor, so read the line rather than going from memory.

1. Open the order (the bell, or **Inventory → Orders**).
2. Tap **View Vendor Report** for the sheet to send:
   - **Copy as text** — paste into WhatsApp or a text message
   - **Email {vendor}** — opens your mail app with the order already written
   - **Download PDF** — a proper purchase order to attach
   - **Print** — a clean sheet, no menus or buttons
3. Place the order with the vendor the way that vendor wants it.

You cannot change the quantities. If a number looks wrong, tell the owner before
you place it.

---

## When the delivery arrives: check it in line by line

Open the order and tap **Check in delivery**.

1. You get one row per item, with **what was ordered** already shown.
2. Type **what actually turned up**. If it matches, type the same number.
3. A row that does not match is flagged straight away: **over** in red if they
   sent more than you ordered, **short** if they sent less.
4. Leave a row blank only if you have not checked it yet. Blank is not the same
   as "nothing arrived" — for nothing arrived, type `0`.
5. Add a note on any row that needs explaining.

Tap **Save delivery**. If anything was over or short, the order is saved and
flagged so the office can take it up with the vendor.

> This is the step that catches a vendor sending more than you ordered. Count it
> in properly, every time.

## Your dashboard

**Inventory → Dashboard** shows four things at a glance:

| Widget | What it tells you |
|---|---|
| This week's count | How many items you've counted, or "Not started" |
| Pending orders | Orders to place, and orders you're still waiting on |
| Low stock | Items at or below their reorder point |
| Variance alerts | Where last week's numbers didn't add up |

Below that, **Recent activity** shows the last five things that happened.

---

## The bell icon

Top right of every page. It shows how many unread notifications you have:

- Monday: time to count this week's inventory
- Any day: an order the owner has approved for you to place

---

## If something looks wrong

| Problem | What to do |
|---|---|
| An item is missing from the count | Inventory → Items → **Add Item** |
| The pack size is wrong (a box now holds 48, not 53) | Inventory → Items → Edit → **Portions per Box/Unit**. Tell the owner; every order quantity comes from this number. |
| The order quantity looks wrong | Tell the owner before you place it. They set the numbers. |
| You submitted the week too early | Ask an admin to unlock it. |
| The vendor sent the wrong amount | Record what actually arrived on the check-in screen. Do not adjust it to match the order. |
